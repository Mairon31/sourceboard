# SourceBoard i18n

`app/i18n/messages/locales/<locale>/<namespace>.ts` is the canonical message
catalog. Catalogs are split by locale and product domain: `base`, `common`,
`editing`, `product`, `settings`, `social`, and `store`.

English defines each namespace's keys. Other locales use `satisfies` against
that English shape, so TypeScript rejects missing or misspelled keys. The
dictionary test also checks every supported locale at runtime. English is a
runtime fallback only; it must not mask an incomplete catalog in CI.

Use `const { t, tp, date, number, relative } = useI18n()` from product UI.
Add a UI string to the relevant namespace in every locale, then use its typed
key through `t`. Use `tp` for plural messages with `.one` and `.other` keys;
use the locale-aware formatters for dates, numbers and relative time.

Never pass user-generated content through `t`: usernames, display names,
bios, post titles/bodies, comments, external metadata and canonical category
data remain exactly as supplied. To add a locale, add all seven namespace
files, register it in `catalog.ts`, and extend `SUPPORTED_LOCALES`.
